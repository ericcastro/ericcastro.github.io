DJ Scrobbler is a desktop app for people who listen to long DJ sets but still want their music history to know which tracks actually played.

It searches and plays DJ sets from YouTube, looks up tracklists when available, and scrobbles each individual track to Last.fm instead of treating the whole set as one generic play.

- Searches and plays DJ sets from YouTube
- Uses tracklist data from 1001Tracklists when available
- Scrobbles individual tracks to Last.fm as the set plays
- Saves favorites, history, playback progress, and theme preferences
- Runs as an Electron app on macOS, Windows, and Linux

This is one of those projects that started as a very personal annoyance and then slowly became polished enough that it felt selfish not to release it.
